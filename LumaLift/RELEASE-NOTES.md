# LumaLift 1.0.0

A new, separate offline video-enhancement app with native SwiftUI, Liquid Glass controls and a pastel pink-purple identity.

Includes genuine bundled Real-ESRGAN enhancement, original-size restoration, 2x/4x output, independent RIFE 30/60 FPS generation, strength adjustment, two-second previews, original audio preservation, a local export library, pause/cancel and thermal safeguards. There are no accounts, uploads, analytics or first-launch model downloads.

**Please read:** this first release still needs physical iPhone testing. Native simulator tests and a physical-device build do not establish phone performance, thermal behavior or long-export reliability. Standard-color SDR input only; output up to 4K, and input up to 1080p for AI interpolation. H.264 MOV export. No 120 FPS or HDR mode. Framewise AI can invent detail or introduce artifacts. Try a short preview before a large export. Keep the app open; interrupted jobs are not resumable after termination.

The original video is never overwritten. System Photos/Files cloud behavior depends on your settings. This is not a metadata anonymizer.

Use the unsigned arm64 IPA with your existing sideloading/signing tool. The source, icon, native build/test report, simulator screenshot and SHA-256 checksums are attached. This is not an App Store release.
